# Bergeys Coffee Co. — website preview

Static site for Bergeys Coffee Co., 1600 Banyan Dr, Venice, FL. Built by RGWebD.

- `index.html`: hero, story, favorites, menu (tabs), catering teaser, gallery and lightbox, Google reviews slider, visit info and map, socials
- `shop.html`: every Bergeron Roasters Square product, linked straight to its own Square page
- `catering.html`: Espresso Bar Package and custom latte art
- `js/reviews-live.js`: optional live Google reviews. Add a referrer-restricted Maps JavaScript API key with Places API (New) enabled.
- `llms.txt`, `robots.txt`, `sitemap.xml`, and JSON-LD (CafeOrCoffeeShop, Menu, Product, Review) for AI and SEO visibility
